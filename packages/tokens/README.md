# @jinx-ui/tokens

Source of truth for Jinx CSS custom properties and style-mode variables.

## Public contract

- Theme variables (`dark`/`light`) on `:root` and `[data-theme]`
- Mode variables for `[data-style="brutal"|"glass"|"minimal"]`
- Radius contract:
  - `brutal`: `4px`
  - `glass`: `14px`
  - `minimal`: `14px`

## Exports

- `@jinx-ui/tokens` -> `src/index.css`
- `@jinx-ui/tokens/tailwind` -> `src/tailwind.css`
